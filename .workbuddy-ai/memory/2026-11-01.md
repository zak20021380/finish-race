# 2026-11-01

## League tiers purged; leaderboard portraits are real Telegram photos

Client-only change, verified by `npm.cmd run build` (exit 0). Built bundle now has ZERO
occurrences of Rookie/Tactician/Strategist/Grandmaster and of `mm-pod-tier` / `vsc-tier` /
`adm-tier` / `ms-tier`.

**Removed (all player-facing tier display):**
- `matchmaking.ts`: `TIER_NAME` deleted; VS pods lose the `mm-pod-tier` chip, the `data-tier`
  aura and the tier from aria. `MindTier` / `tierOf` / `myTier` survive as INTERNAL only — the
  queue still sends `tier` (wire contract, not a chip). Status copy no longer says "tier".
- `vsclash.ts` + `vsdata.ts`: the 3-pip `vsc-tier` glyph and its word are gone; `Fighter.tier`,
  `RivalPersona.tier`, `tierOfTiq` deleted. `VsStakes.tier` is KEPT — it is the bot difficulty
  ("HARD") on the stakes pill, not a league.
- `compete.ts`: `TIER_NAME`/`TIER_BAND`/`DIVISION`/`divisionOf`/`tierOf`/`TIQ_PER_WIN` deleted;
  the Top Minds strip's tooltip no longer names a division or a "N wins to X" milestone.
- `menu.ts`: profile TIQ pill reads "N Tactical IQ" (no "Rookie II").
- `admin.ts` + index.html + CSS: the Mind-tier preview tool is gone (with the chip gone it
  changed nothing). `runtime.tierOverride` and `AdminApi.tier()` deleted.
- `#ms-tier` → `#ms-sub` (it is the guild kind line, never a tier). `sqp-crest[data-tier]`
  arena metals deleted — one sky crest for every squad.

**Portraits:**
- `minds.ts` `localRow` now falls back to `telegramAvatarUrl(username)` when `photo_url` is
  absent (imports `squads.ts`; that module already cycles with matchmaking, so no new hazard).
- `paintFace`/`paintPhoto` take `eager`; podium + standing strip load eager + fetchpriority.
- `home.ts` ladder rows are `loading=eager`, top 3 get `fetchpriority=high`.
- `openMind` now paints the seat's real photo in the mind sheet (`msHead(..., photo)`).
- `.mind-av` restyled from a neon cyan/indigo orb to the same clay disc the podium uses, so a
  missing photo is a clean letter, not a glowing placeholder.
- `.mind-av .mind-flag` now uses `inset-inline-*` (Persian RTL).

**Also:** `flags.ts` renamed its two-step image fallback attribute `data-tier` → `data-step`
(nothing league-related, but it was the last `data-tier` in the DOM); the dead
`customMatchmakingDesc` copy ("Region & Skill tier") was deleted from en + fa.

**Left on purpose:** `matchmaking.ts` still sends `tier` on the queue params and validates it off
the opponent payload (`MindTier` / `tierOf` / `asTier`). That is the matchmaking wire contract with
`worker/matchmaker.ts`, never rendered — removing it is a protocol change, not a UI change.

## Home Mind Ladder card: AAA obsidian pass

`index.html` + `home.ts` + `style.css`, verified by `npm.cmd run build` (exit 0).

- **The `•` capsule is gone.** `.mind-trend` (a fixed 30px pill that rendered a lone dot for a
  steady rank) is deleted; the row's trend is now `.mind-delta`, a bare 9px `▲n`/`▼n` inside
  `.mind-id` and only rendered when `trend !== 'same' && delta !== 0`. That handed ~37px back to
  the handle, which is why real usernames stopped ellipsizing to six letters.
- **Row anatomy is fixed at four cells**: `.mind-rank` (minted shield) → `.mind-av` (28px portrait,
  conic metal ring + `::before` clay disc inset 2px) → `.mind-id` (`.mind-nm` + delta) →
  `.mind-score` (gold value + violet `TIQ` + gold `.mind-brain`). `li.dataset.rank` is the ONE
  styling hook for podium tinting (`[data-rank="1|2|3"]`), never a class on each child.
- **Shield** = `border-radius: 8px 8px 13px 13px / 7px 7px 16px 16px` (flat shoulders, rounded
  point) + metal gradient + specular top stop. Gold #1 carries `.mind-crown` (`#i-crown`) INSIDE
  the shield as a flex column — no negative offsets, so a 24px compact row can never clip it.
  Empty seats hide the crown and drop all metal.
- **Header** `#mind-top` is now a seasonal crest (`#mind-season` = `Season ${arena().seasonNo}`,
  gold hairline + `.mind-pulse` radar ping). The head-count moved to `title`/`aria-label`.
  `paintMindTop(null)` runs synchronously at mount so the crest never flashes "Season 1".
- **YOU strip** centre pill is `of <b>#home-mind-field</b> minds` — the percentile is gone.
  `.mind-mine` is the cyan neon-glass variant of the shared `.hud-mine` (scoped, so Nations Cup
  keeps its own bar). `#home-mind-pct` was renamed `#home-mind-field`; `.hm-pill-u` hides ≤360px.
- **CTA** = obsidian slab (radius 14, not a pill) + violet hairline + `::before` light cap +
  `.mind-cta-go` chevron chip; `:active` is `scale(.985)` at (0,4,0) so it beats `.card-cta:active`.
- Empty rows are `border: 1px dashed` frosted slots with `#i-lock` in the portrait.
