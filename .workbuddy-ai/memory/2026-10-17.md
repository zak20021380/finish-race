## Friends lobby: entry pane + live lobby + host match-format (client + worker)

Rebuilt `#sheet-game-modes`'s friends flow into three panes — the mode list, an entry pane
(`#gm-view-room`) and a live lobby (`#gm-view-lobby`). The old pane stacked a create key, a code
block, a coral invite slab and a join form in one view; that is gone.

**New `src/lobby.ts`** — the roster as a value, not DOM: `Lobby` + pure `seatIn`/`vacate`/`setMode`/
`setTeam`/`balanceTeams`, `openLobby()` returning a `LobbyHandle`. `vacate()` promotes the lowest
held seat, which is host migration done once, where it cannot be forgotten. The socket is optional:
after `CONNECT_MS` (1400ms) with no `LOBBY` frame the screen falls back to a **solo** lobby where the
host may add bots; `fallback()` sets a `solo` flag *before* closing, or the close handler reports a
dropped connection on a lobby that never had one (that bug cost a debugging round).

**Worker** — `?roomcode=NNNN&host=1` mints a code lobby (4 seats, never auto-paired, no timer);
a guest must be expected or `room_not_found`. Frames out: `LOBBY` (roster + crown + mode + teams +
`you`), `ROOM_FOUND` (now with `mode`, `teams`, per-seat `id`/`team`). Frames in: `SET_MODE`,
`SET_TEAM`, `ROOM_START`, `CANCEL`. Host-only, seat-scoped; `lobbyDepart()` migrates the crown.
The two-player minimum is **code lobbies only** — the `?room=<n>` auto-pair room must still launch
solo (three matchmaking checks caught that).

**Race** — `LobbyRace` is structurally `OnlineSession` (`side: number`, `sizes: number[]` widened),
so `startGame()` runs a room race with no second path; `main.ts` builds the dock's `Room` from the
roster (`roomFromRoster`, trailing wells trimmed, min 2). Team mode is lobby-level: teams are
assigned/synced/painted but the board still plays one ball per seat.

**CSS** — entry + lobby in Dark Clay (`.fr-*`, `.lb-*`), gold `is-lobby` Start, `.lb-actions` swaps
the picker into the Leave key's slot so opening it shifts nothing. `[hidden]` must be restated on
`.gm-view`, `.gm-foot`, `.gm-rewards`, `.lb-pick`: an author `display:flex` outranks the UA rule
(this is why the entry pane stayed visible over the lobby for a round).

matchmaking 56/56, new `verify-worker-lobby.mjs` 36/36, race 52/52, admin 103/103; new

## Friends lobby round 2: one format knob, the VS arena, self team moves

Replaced `SET_MODE`/`mode` with a single **format** model, shared by client and worker (`src/room.ts`):
`LobbyFormat = '2v2'|'2v1'|'3p'|'4p'` derives everything — `FORMAT_CAPACITY` (4/3/3/4), `FORMAT_MODE`
(team/team/ffa/ffa), `teamCapacity` (2v2 2/2, 2v1 Blue 2 / Red 1, else capacity), `defaultTeam` =
seat parity, `formatOfMode` ('team'→2v2, 'ffa'→4p). `reflowSeats`/`reflowRoom` resize a room around the
seated people (a seat that fits keeps its index; the impossible is `null`); `assignTeam` moves a seat
with caps — full destination means **swap with the lowest seat on it**. `nextTeam(blue, red, fmt)` is
one helper shared by the client's `teamFor` and `gamemodes.ts`'s `plannedTeam`.

**Client**: `Lobby.format`; `setFormat` is the pure switch (returns the same object when nobody fits);
`canStart`/`minToStart` (`2v1` = exactly 3); `startHint` feeds `#lb-hint`. UI: mode row
Individual/Team Match + a second row whose two chips swell with the mode (3p/4p ⇄ 2v2/2v1),
`FORMAT_LINE` under it. Team view is a **VS arena**: Blue/Red columns both drawn `max(cap)` rows,
Red's non-existent cell is `.lb-lock` (2v1 reads as 2 vs 1), gold `#i-swords` medallion between them.
FFA keeps the 2x2 grid with per-seat colour chips (Blue/Red/Green/Yellow). Seats in team view are
shorter (50px, 46 under 660px) so 360x640 never scrolls. A player may move **their own** seat between
teams; host moves anyone; `[hidden]` on format chips leaves the grid, never reserves space.

**Worker**: `SET_FORMAT` in (validated), `SET_MODE` kept as an alias for old clients;
`applyFormat` = reflow + rebuild (`FORMAT_DENIED` to the host, `broadcastLobby` when the room cannot
take the pick — every seat stays put); `SET_TEAM` self-or-host, team modes only; `?room=<n>` auto-pair
keeps `formatForSize` (3→'3p', else '4p'). `ROOM_START` min: 3 held for 2v1, 2 otherwise.
