# 2026-10-16

## Arena hero header — redesigned (CSS only, no markup or TS change)

Scope: only `.stars-head` in the 200 Stars Cup — the Star emblem, the wordmark, the
bracket clock and the two-way switch. Everything below the switch untouched.

What changed in `src/style.css`:

- **Emblem is now a set jewel, not a floating decal.** `.stars-emblem` keeps
  `background-color: transparent` and gets its gold rim from a *gradient fill* behind a
  padded `::before` (`padding: 1px` + `inset: 1px`), never a border — so the
  "no opaque box / no black cutout" audit still passes. `::before` is the lit dark face
  (`z-index: 0`); the PNG is `position: relative; z-index: 1` at **74%** of the face so
  the rim stays a visible ring. It now carries a gold bloom (box-shadow), which the old
  verifier explicitly forbade.
- **Wordmark is clipped metal.** `linear-gradient(180deg, #FFFFFF 0/56%, #E4EBF6 82%,
  #B9C7DE 100%)` + `background-clip: text`, `color: transparent`, engraving via
  `filter: drop-shadow(...)` (a `text-shadow` would show through a transparent fill).
  Wrapped in `@supports ((-webkit-background-clip: text) or (background-clip: text))`
  with the plain `#F8FAFC` fallback outside, because a silent clip failure would erase
  the championship's name.
- **Clock is a dark glass capsule** (`display: inline-flex`, `border-radius: 999px`,
  translucent `rgba(13,20,34,.6)` fill) with a gold hairline, a warm bloom and a 5px
  **breathing bead** `::before` (`@keyframes cup-clock`, 2s). Text content is untouched,
  so `role="timer"` and the `HH:MM:SS` read stay identical. Grew 59.9px → 70.7px wide.
- **Switch**: deeper inset well; the thumb keeps its geometry but gets a gold hairline
  rim, a warm top wash and `var(--motion-med)` on the slide. Inactive label #8593AB.

### The palette rule (worth keeping)

Gold = live/premium (the Star's setting, the clock's bead, the lit key's rim).
The wordmark is cool silver. This keeps **PLAY FOR YOUR SQUAD** the only solid gold slab
on the screen — the file already has a comment saying the one loud action must stay
loud. Don't gold the title.

### Geometry is a hard constraint — do not add rows

`.stars-head` is budgeted at **≤ 60px** because the card must not scroll at 360x640.
Measured head: 58px @360x640, 60px @390x844, 54px @320x568. Row 1 has ~80px of
*horizontal* slack at 360 (title box 206px, text run 126px) but only ~2px of vertical
slack, so the redesign is styling-only. The emblem sizes 24/26/22 come from the
existing `max-height: 600px` / `max-width: 352px` / `min-height: 780px` blocks; the
`::before` radius steps 8/8/6 with them.

  `emblem.shadow !== 'none' → fail` encoded the *old* design and was replaced with the
  new intent (transparent bg, no border, gradient rim + face, gold bloom, PNG 60–86% of
  the box, `mix-blend-mode: screen`). Added a `hero` block to its PROBE asserting the

  and the thumb's gold rim.

**Gotcha:** a regex written *inside* a PROBE template literal needs `\\s`, not `\s` —
the template literal eats the backslash and `/245,\s*158/` silently becomes
`/245,s*158/`, so every "is it gold?" test returns false. Bit me once here.
