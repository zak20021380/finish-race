## Leaderboard "your rank" bar — overlap fix + 3-zone HUD

- **Root cause of the row-#5 overlap**: `.mind-podium`/`.mini-rank` were `flex:1 1 auto; min-height:0`
  while rows kept `min-height:40px`, so the band was allotted less than its content and the rows

  `position:absolute`.

  required widths (320/360/390) always show all five rows.

## Persistent invite rooms + background host + single-use codes

- **Root cause of "Room does not exist"**: `roomLeave()` in the worker treated a closed socket as a
  departure — `lobbyDepart()` deleted the lobby when the host's last socket went away, so the friend
  tapping the link seconds later got `room_not_found`.
- **Worker** (`matchmaker.ts`): `RoomMember.connected/droppedAt`, `LiveRoom.lastSeenAt/hostPending`.
  A dropped lobby socket now HOLDS the seat (crown = full `ROOM_IDLE_TTL_MS` 10 min, guest =
  `ROOM_SEAT_HOLD_MS` 60 s, swept by `sweepLobbies` from `alarm()`); `rearm()` arms both clocks.
  A missing room is created by WHOEVER arrives first (guest first ⇒ `hostPending`, seat 0 reserved);
  `seatFor()` reclaims a seat by player id (newest socket wins, old one closed) so a reconnect never
  meets `room_full`/`room_exists` from its own ghost. `LEAVE` (new ClientMessage) from the host =
  `disbandLobby` + `retire(code)`; `launchRoom` also retires the code. Spent codes live in a 30-min
  `retired` map ⇒ `room_consumed` ⇒ client toast "invite used or expired". Disconnected seats become
  `takeover()` bots at launch so a held chair can never stall the board.
- **Client** (`gamemodes.ts`): a room is a MEMBERSHIP — `RoomSession {code,host,invite,at}` in
  `sessionStorage` (`detour.room.session.v1`), `activeCode` mirrors it. `connect()`/`openRoom()`/
  `resumeRoom()` split; `onDrop` → `scheduleResume` (300/800/1600/3200/5000 ms, gives up after 5);
  `visibilitychange` + every non-game route call `resumeRoom()`. `×`/backdrop/`<` only `hideLobby()`;
  only `#lb-leave` sends LEAVE. Guest arrival (`noteArrival`, live frames only) pops the drawer +
  haptic + the countdown, which is now gated on `lobbyOnScreen()` and `roomFull()` (any format).
- **One invite URL**: `telegram.ts` `roomInviteUrl/roomShareUrl` is the only builder; `gamemodes`
  `inviteUrl()`/`buildInviteLink()`/`buildShareUrl()` read `activeCode`; `#lb-code` prints that code
  and carries `data-invite`. `createRoomCode()` never repeats a code in a tab (sessionStorage ring).
- i18n: `errInviteExpired`, `errRoomClosed`, `errRoomExpired`; countdown copy is format-neutral now.
- Gotcha: `lobby.ts` must NOT flip `status:'live'` on socket open — the placeholder roster would be
  read as a real one and every reconnect would look like a guest arriving.
