# 2026-10-14 — Shop showcase mode (disabled / not-for-sale)

## What changed
Temporary "Disabled / Not For Sale" showcase mode for the shop. Only shop-facing files touched:

- `index.html` — added `.shop-closed` inset gold-edged banner between the `.seg` tabs and
  `#shop-grid`; added a second `.note` toast host inside `#s-shop` so refusals are visible there.
- `src/style.css` — new `.shop-closed*` banner block; `.cos` converted to the canonical clay
  recipe (`--clay-face` + `--clay` + `--clay-ring`, **backdrop-filter removed**); `.cos-btn` is now
  `inline-flex` with a `.cos-lock` glyph that ships hidden; `[data-state="locked"]` rules stack the
  foot, dim `.cos-price` to 0.4, and give the capsule a full-width 48px recessed face.
- `src/shop.ts` — `SHOWCASE` flag + `SHOWCASE_NOTE`; `stateOf()` collapses every non-equipped item
  to `locked`; card markup gained a lock glyph + `.cos-lb` label span; `refuse()` (impact light +
  `api.note`); guards at the top of both `act()` and the `yes` click handler; a card-body click
  listener so a locked card refuses wherever it is tapped. `ShopApi` gained `note()`.
- `src/main.ts` — `noteEl` (single) became `noteEls` (every `.note` on the page); `showNote` now
  writes to the note host of whichever `.screen` is visible, so a shop refusal never leaks onto the
  board toast. `createShop({ ..., note: showNote })`.

Key detail: the locked capsule uses `aria-disabled`, **not** the `disabled` attribute — a real
`disabled` button swallows the click before the guard can speak.

finish here because `esbuild.exe` cannot execute at all (even `esbuild.exe --version` exits 1 with

inset ring and `backdrop-filter: none`; classic = Equipped (44px, untouched); neon/gold/obsidian =
"Not for sale" 48px with the padlock and price opacity 0.4; no horizontal overflow at 320/360/390/
430; refusal toast fires and coins stay at 1,850 with the buy sheet never opening. Screenshots in
`.shots/shop-360-closed.png` and `.shots/shop-360-closed-walls.png`. Game screen re-smoked
(`.tmp/smoke-game.mjs`) after the `main.ts` note change: board canvas 640x960, no exceptions.

# 2026-10-14 (2) — Admin Command Center (FAB + live-ops stage)

## What changed
- **`src/admin.ts` (new)** — two halves. (a) The **live runtime config** `runtime` (persisted at
  `detour.admin.v1`): `salesOpen, hazards, maintenance, broadcast, winTiq, coinMult, blitz,
  radiusNormal, radiusWide, tierOverride`. `setRuntime()` is the single writer (patch → persist →
  notify `onRuntime` watchers); `loadRuntime()` folds a hand-edited blob field by field.
  (b) `createAdmin(api)` wires the FAB, the overlay, its 3 tabs and every control.
  Access: `ADMIN_IDS` + `VITE_ADMIN_IDS` allowlist, or the dev door (no Telegram user, or a
  loopback hostname) so a plain browser can test it. `tiqFrom(wins, games, bonus)` is the ladder
  formula — the win reward folds the race credit in, so the 140 default is byte-for-byte the old
  120/win + 20/race.
- **`index.html`** — `#home-broadcast` strip (first child of `#s-home`), `#btn-admin-fab` (last
  child of `#s-home`), `#overlay-admin` full-viewport stage (3 clay tabs: Live Ops / Economy &
  Rules / Quick Tools).
- **`src/style.css`** — appended ADMIN section (~490 lines): `.admin-fab`, `.home-broadcast`,
  `.admin`/`.admin-tabs` (56px track) / `.adm-sw` / `.adm-steps` / `.adm-tool` / `.adm-tier-ring`.
  No `backdrop-filter`; every control >= 48px.
- **`src/shop.ts`** — `SHOWCASE` const replaced by `api.salesOpen()` (read at paint time) and a
  public `Shop.refresh()`.
- **`src/matchmaking.ts`** — `myTiq()` → `tiqFrom(...)`; new `myTier()` (honours
  `runtime.tierOverride`); `pickRival` uses the runtime radii; the radius chip, win-stake TIQ and
  coin stake all read `runtime`. Removed the now-dead `TIER_RADIUS`/`WIDE_RADIUS`/`TIQ_PER_WIN`.
- **`src/main.ts`** — `queueMatch()` is the one door every queue goes through (Maintenance Lock
  gates it); hazards/blitz/coin-multiplier read `runtime`; `admin` is closed first in `onBack()`;
  `onToggle` shows the Telegram BackButton while the stage is up; `onRuntime` → `shop.refresh()`.
- **`src/storage.ts`** — `Save.tiqBonus` + `earnTiq()`; `payout()`/`recordGame()` take a `mult`.
- **`src/telegram.ts`** — `TgUser.id` (the allowlist key). **`src/vite-env.d.ts`** — `VITE_ADMIN_IDS`.
