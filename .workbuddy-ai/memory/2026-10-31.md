## Post-match banter overhaul (banter.ts / banter.css / index.html / settings.ts)

- **Bubbles are now flex children of `.result-seat`**, not absolutes spanning the card. `width:
  fit-content; max-width: 68%; margin-inline-start: auto` → they park at the inline-end and can
  never cover the avatar/nameplate. The `.is-speaking > .result-id { opacity: .12 }` fade is gone.
- **`is-emote` mode**: a message that is only pictographs (`\p{Extended_Pictographic}` + joiners/
  VS/skin tones, no letters or digits) renders as a 42px circular glass medal with a spring
  `banter-emote-in` on the bubble and a `banter-emote-pulse` on the inner span.
- **Dock is frameless, two rows.** Row 1 = six 36px circular faces + a 36px composer toggle at the
  inline-end. Row 2 = `.banter-row-swap` grid where the chip rail and the composer share
  `grid-area: 1/1`, so the toggle swaps them **in place** (no third storey). `#banter-toggle`,
  `#banter-toggle-ico` (href swaps `#i-chat` ↔ `#i-close`), `#banter-close` are new ids.
- **`[hidden]` needs `!important`**: an author `display: grid|flex` outranks the UA `[hidden]` rule.
  `.result-say[hidden], .result-banter[hidden], .result-banter [hidden] { display:none!important }`
  — without it the dock rendered even for 3/4-seat parties and empty bubbles ate padding.
- Copy is 2–4 words per taunt in en + fa (`banterWin*`, `banterLose*`, `banterBot*`), plus new keys
  `banterComposeOpen` / `banterComposeClose`. ru/ar/es still fall back to en.
- Relay (`POST_MATCH_CHAT`), the 1.2s bot reply and `opponentLeft()` locking are untouched.

## Enlist Squad: case-insensitive handles + real getChat (squads.ts / menu.ts / worker/squads.ts)

- **One handle rule, `i` flag.** `HANDLE_RE = /^[a-z0-9_]{4,32}$/i` (+ `HANDLE_MIN/MAX`) in
  `src/squads.ts`; `worker/squads.ts` mirrors it as `/^@[a-z0-9_]{4,32}$/i`. Uppercase is legal —
  `computerScience55` was being refused as `chars` on the old lowercase floor.
- **New `bareHandle()`** folds a `t.me` link, the typed `@` and outer whitespace in ONE place;
  `handleIssue`, `cleanHandle`, `cleanChatReference` (now a one-line delegate) all read through it.
  `cleanHandle` no longer silently deletes *inner* spaces, so `"Doge Squad"` is refused, not mangled.
- **`@` never marks the field invalid**: `normalise()` strips it on the keystroke (caret preserved),
  so a lone `@` leaves an empty-but-clean field. `clearError()` runs before every re-judge, so the
  red line dies on the same keystroke as the corrected character.
- **Loading state on the key itself**: `setPhase()` now shows `#enlist-spin` for BOTH phases (it was
  register-only) and sets `aria-busy`; label = `enlistVerifying` → "Verifying on Telegram…".
- **Backend getChat is a GET** (`?chat_id=`), per the Bot API shape, via a `verb` arg on `telegram()`.
  400/404 → `chat_not_found` "Channel or group not found on Telegram."; 403 → private; type mismatch
  (channel vs `supergroup|group`) → `kind_mismatch` + `kind`, copy "Handle belongs to a group, not a
  channel. Switch to the GROUP tab." (was "This handle belongs to a group…").
- Copy: `enlistErrHandle` 4–32, `enlistErrShort` ≥4, `enlistErrNotFound` names Telegram (en + fa).
- Verified with `npm.cmd run build` only (exit 0); bundle carries `/^[a-z0-9_]{4,32}$/i`.

## AdsGram SDK core (ads.ts new, index.html, vite-env.d.ts, settings.ts) — phase 1 of 3

- `<script src="https://sad.adsgram.ai/js/sad.min.js" async>` sits right after the Telegram script
  in `<head>`; the async load is load-bearing (a blocked CDN must never delay boot).
- **`src/ads.ts` is the only ad door.** Vendor surface typed locally (`AdsgramSdk.init({blockId,
  debug})` → `AdsgramController` with `show/addEventListener/removeEventListener/destroy`) and
  `Window.Adsgram` augmented via `declare global`. No `any`.
- Block ids: `VITE_ADSGRAM_{RECOVER,COINS}_BLOCK_ID || VITE_ADSGRAM_BLOCK_ID || ''`;
  `VITE_ADSGRAM_DEBUG === 'true'` (trimmed). All four keys added to `ImportMetaEnv` in
  `vite-env.d.ts` — undeclared keys are a hard TS2339 under strict.
- `playRewardedAd()` **never rejects**: mutex `isShowingAd` (a racing tap answers `skipped`),
  `no_sdk` for a missing SDK *or* empty block id, reward on `onReward` **or** `done===true &&
  !error`, no-fill sniffed from `description|state|reason` (`NO_FILL_RE`), listeners removed +
  `destroy()` in `finally` so a throw can never leak the mutex.
- Quota: `fr_tiq_recovery_log_v1` (NOT a `detour.*` key) holds epoch stamps, rolling 24h window,
  max 3. The log is hydrated from storage once and then held in memory, so a webview that refuses
  localStorage still enforces the limit this session. Per-match claims are a separate `Set`.
- `isAdPlaying()` / `adBlockId()` exported for the UI phases. strings: `adRecover*`, `adDouble*`,
  `adToast*` in en + fa (ru/ar/es fall back to en).
- Verified with `npm.cmd run build` only (exit 0); dist/index.html carries the CDN tag and both
  locales' strings survive in the bundle. ads.ts is not imported yet → tree-shaken out until phase 2.

## Reward wiring: claims, count-ups, audio hold (main.ts, audio.ts, style.css, index.html) — phase 3

- **`showOverlay()` is the only init point**: `resetMatchClaims()` first, then both busy flags off,
  both spinners hidden, `is-refunded` off, toast cleared — before `resultView` exists, so the
  first `paintResultCopy()` paints a clean slate.
- **`paintRewardButtons()` hangs off `paintResultCopy()`**, so the `onLang` callback at the bottom
  of main.ts re-reads every label for free. Recover chip: hidden unless `!won && stake > 0`;
  `.is-claimed` wins over `.is-exhausted`; the quota badge is hidden once claimed or at 0, because
  `adRecoverLimit` already spells "LIMIT 0/3". Double chip: hidden unless `coins > 0`.
- **The refund is `earnTiq(stake)`** — `tiqFrom` adds `tiqBonus` linearly, so the rating moves by
  exactly the stake. `earnCoins(bonus)` is the 1× extra that makes 2×. Both flush → `onChange`
  repaints the profile pill (`p-coin`, count-up via `setBalance`) and `paintSeatIdentity()` the TIQ.
- **Audio: new `holdAudio()`/`releaseAudio()` in audio.ts** — a `adHold` flag zeroes the master gain
  and makes `play()` refuse at the door; it never touches the saved volume, so it cannot leave the
  game silent. Called around `playRewardedAd(...).finally(releaseAudio)`.
- **Count-ups**: `animateClaim(ms, paint, store)` is the one clock (rAF + cubic ease, snaps under
  reduced motion). `stakeRaf`/`coinRaf` are separate handles added to `clearResultMotion()`, so a
  coin claim can never freeze the stake. Stake 520ms → `0 TIQ` + `.is-refunded` (crimson band turns
  emerald, kicker becomes `adRecoverProtected`); coins 500ms from `+X` to `+(2X)`.
- **`#ad-toast` is new** (last child of `.overlay.result`): the board's `.note` lives at z-index 4
  under the overlay's 10, so a result toast needs its own surface. Absolute, `pointer-events:none`,
  so it costs the card no height and never blocks the keys under it.
- Cross-chip guard: `if (recoverBusy || doubleBusy) return;` — the SDK's mutex would answer
  `skipped`, which reads as the player's fault instead of a tap that arrived too early.
- `.is-consolation.is-doubled` keeps the coin pill lit on a defeat: the tint moves to the pill's
  children so the CTA never looks disabled.
- Verified with `npm.cmd run build` only (exit 0, 72 modules — ads.ts is finally in the graph).

## Squads — real membership, no mock rosters (18:2x–19:0x)
- **The roster is the only source of members.** `RegisteredSquad` (worker/squads.ts) now carries
  `subscribers` (Telegram `getChatMemberCount`, external stat only), `roster: SquadMemberRow[]`,
  `creatorId`, and a derived `members = roster.length`. `readRegisteredSquad` moves a legacy row's
  `members` into `subscribers` and seeds the owner as the single leader, so an old row reads as a
  squad of one instead of a squad of 1,240.
- Worker routes on the singleton DO: `POST /api/squads/{join,sync,leave,kick}`, `GET
  /api/squads/{board,squad?id=}`; `worker/index.ts` forwards the whole `/api/squads/` prefix.
  A join is the ONLY door that adds a row (sync never enrols); one squad per player — joining
  removes them from every other roster in the same turn. Leader leaving passes the crown to the
  longest-serving member, or disbands the squad when they were the last player.
- Client: `src/squads.ts` has no SEEDS. `getSquadRanking()` ranks only real rows (own creations +
  the last board read); `squadRosterOf()` refreshes the local player's row from `myTiq()` on every
  read; `myRosterId()` falls back to `'local'` outside Telegram. `src/squadRoster.ts` is now a
  projection (no FIRSTS/LASTS, no splitTiq, no squadTargetAvg) — `buildSquadRoster` reads only the
  roster. `getChannelRoster` (data/index.ts) reads the same roster, so the Cup cannot invent a name.
- Invite grammar: `squad_<id>` → `shared/config.squadAppLink` (`t.me/<bot>/app?startapp=squad_<id>`),
  parsed by `telegram.inviteSquadId()` (start param → `?squad=`), dispatched from `main.ts` as
  `detour:squad-invite` → menu opens the preview card (a PROMPT; only Join writes the roster).
- UI: `.sq-admin` bar under `.sq-you` (ADMIN chip + `#squad-invite-copy` + `#squad-invite-share`),
  `.sq-kick` per non-leader row, `.sq-solo` note for a one-member squad, `.sq-meta-subs` for the
  audience. Leader pill now reads `squadLeader`. EN+FA keys: copyInviteLink / linkCopied /
  kickMember / squadLeader / adminBadge + squadErr* family.
- Empty-field fallbacks: `.stars-run.is-empty` on the Cup board, `.sr-empty` in the roster sheet,
  Home ticker says "No squad yet", the squad notification seed is gone.
- Build only (no suites), `npm.cmd run build` exit 0.
